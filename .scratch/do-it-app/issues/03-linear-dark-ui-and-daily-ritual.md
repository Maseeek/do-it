## Question

What is the exact screen and tab hierarchy for the Linear dark mode mobile PWA? How should the daily habit checklist feel (e.g. haptic micro-interactions, optimistic point ticker, collapsible categories), and how should the head-to-head versus duel and stakes vault be visualized?

## Answer

Constructed 4-tab Linear dark mode mobile PWA:
1. Today: 1-tap tactile habit checklist, daily par counter (250 pts), completion progress bar, photo proof capture modal.
2. Duel: Real-time Machek vs Myra head-to-head split comparison bar across Weekly, Monthly, Yearly, and Karma tiers, countdown to reset, active stake card, and side-by-side mutual checklist activity.
3. Stakes: Active weekly & monthly wagers, presets, and Hall of Fame for claimed stakes.
4. Vault: Lifetime Karma podium, Habit Manager for full editing/rebalancing, device profile switcher, and cloud database settings.
